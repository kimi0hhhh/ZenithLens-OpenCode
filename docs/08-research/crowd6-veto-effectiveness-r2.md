# crowd6 六维复合否决有效性调研（R2）

> 研究问题：**拥挤度六维复合否决（crowd6）到底有用吗？** 用系统自己的数据与走前方法论给出可复核结论。
> 只读纪律：未修改任何 `.py` / 数据 / 台账 / 工件；复算脚本仅在临时目录（路径见 §B.0）；
> 未调用会写盘的分析 API（`factor_engine.evaluate` 以 `use_cache=False` 调用，`build_adopted_pan` 未调用）。

## 摘要（结论先行）

**结论：证据不足** —— 现有证据既不足以证明 crowd6 有可用的 T+1 判别力，也不足以判定它有害；但它当前「无牌照却持生产否决权」的状态不能维持，应进入复核流程。

三组核心证据：

1. **全触发域无判别力**：18 资产走前复算，551 个 E1/E3 触发日中 crowd6 可用 515 个；亮灯组 vs 未亮组 T+1 涨率 **53.2% vs 52.4%**（Δ+0.8pp，p=0.87；生产 `veto_status` 口径 +1.5pp，p=0.76）。触发日全集 52.5% vs 基线 52.68%，lift 0.996（p=0.91）。
2. **出口链方向正确但不显著**：在真正会被否决影响的 `p_up>0.52` 触发日子集（n=269）中，被 crowd 否决日 T+1 涨率 **47.7%~48.3%** vs 通过日 **58.9%~59.1%**（Δ≈-11pp，p=0.078~0.101，95%CI 含 0）。该子集样本量下 MDE≈18pp，**样本不足以判定**（§B.7）。
3. **没有「扛事的维」，且另一半否决（klow2）方向反了**：六维逐维无一显著（p 全部>0.2；全触发域中仅 mom5 方向正确 -2.9pp，vpcorr/volat 方向相反）。对照之下 klow2 亮灯日 T+1 涨率反而**更高**（57.6% vs 46.3%，p=0.010），即双否决中的 klow2 在本样本内是负贡献；生产出口链（54.2%）与全关（55.4%）不可区分（p≈0.85）。

治理侧：crowd6 牌照 `none`（总分 21.4 < 候补线 50，按机制 §5.2「未达线=不入盘」）、准入 `rejected_f2`（其中 F2=1.0 是 id 自碰撞伪影，§A.1）、死亡条件（`lift(m24)<1.00`）尚未触发（m24=1.0113）。

**建议**：进入复核流程（先修两个评审口径 → 重新判定牌照；复核结论前不应继续持有生产否决权，可降为影子观察）。不建议「保持现状」。

### B. 走前反事实实验

#### B.0 方法与口径（可复算）

- **数据**：`data/cache/bars/*.json` 全部 **18 个**资产（各 320 根日线，2025-05-26..2026-09-11）。当前监控持仓对应 13 个 proxy，缓存另含 5 个历史资产（159781/159920/162411/512050/515050），按任务要求全部使用。
- **机制**：直接复用 `engine.features_at / gate_of / train_model / predict_at / veto_status` 与 `factor_engine._crowd_fired / _klow2_fired`（每折训练段重算归一化、purge=H+2=3、冻结参数原样；未调参、未随机切分）。
- **触发日样本**：551 个 E1/E3 日；crowd6 复合可用 515 个（36 个早期样本训练段不足）。
- **基线**：全部资产-日 n=5742，恒涨率 52.68% > 恒跌率 47.32% → `max(恒涨,恒跌)=52.68%`（与系统冻结口径一致）。

- **脚本**（只读，临时目录）：`C:\Users\10719\AppData\Local\Temp\opencode\crowd6_b_walkforward.py`（复算）、`crowd6_b_stats.py`（对照）、`crowd6_b_dim_exit.py`（逐维/出口）、`crowd6_eval_replication.py`（六窗复核）、`crowd6_a_ledger_stats.py`（台账）。

#### B.7 统计功效（为什么判「证据不足」而不是「无用」）

- 全触发域：观测 Δ+0.8pp；当前 n=158/357 下 MDE（80% power，α=0.05 双侧）≈ **13.4pp** → 只能排除大效应，不能排除中等效应。
- 出口链子集：观测 Δ≈-11pp；当前 n=89/180 下 MDE ≈ **18pp**，观测幅度低于 MDE → 不显著。若该效应为真，要 80% 功效检出约需「259 个被否决日 + 519 个通过日 ≈ 777 个候选」（当前 269）→ 按当前 0.84 候选/交易日，还需约 **2.5~3 年**。
- 多重比较：本报告含 6 维 × 2 域 + 4 口径 + 分时段；任何单点 p=0.078~0.10 未经校正都不构成证据。

分时段参考：前段（holdout 起点前）：crowd 走前 52.6% vs 53.0%（Δ-0.5pp，p=0.93）；后段（近 60 日）：57.1% vs 50.0%（Δ+7.1pp，p=0.56）。后段出口链：crowd 否决 2/8=25.0% vs 通过 21/36=58.3%（p=0.088）——方向与全样本一致，样本更小。

#### B.8 局限

1. **单市场、小资产池**：13~18 只境内 ETF 代理；触发样本被 3 只资产主导（518880 黄金 88 次、162411 油气 86 次、513100 纳指 77 次 = 全样本 46%）。
2. **口径**：T+1 代理日线收盘对收盘（与系统一致），不等于基金净值；除权修正沿用系统口径。
3. **相关性**：同资产连续触发 103/551（18.7%），H=1 下不重叠但序列相关；未做聚类稳健校正（governance 独立触发日口径也只去重叠不校正自相关）。
4. **时段**：复算覆盖至 2026-09-11，**包含** 2026-09-12 评分时冻结的 60 日 holdout。作为用户指定的复核已披露；全程未调参、未用于任何选择。
5. **台账窗**：60 日台账去重后仅 20 个 proxy-日触发，单独无判定力。

### C. 结论与建议

**三选一判定：证据不足。**

- 「有用」不成立：全触发域零判别力（p=0.87）；出口链正向趋势未过显著（p=0.078~0.101）；六维无一扛事；治理无牌照、总分 21.4 远低于 50 线。
- 「无用」不严谨：出口链的三个切面（全样本、近 60 日、60 日台账）方向一致（被否决日 T+1 涨率更低，见 §B.5/§B.7），只是样本不足以确认。
- 结论：**不能维持其生产否决权**（`license=none` 按机制 §5.2 本就不该在盘），但值得**进入复核流程**决定去留。

复核流程建议动作（按优先级）：

1. **修 F2 伪影**：`factor_engine.BUILTINS`/`_incumbent_series` 的 id 碰撞（crowd6 评估时把「crowd」当现役对照 → 自比 1.0），修复后重跑 F2/F3。
2. **修 veto 因子的 F1 方向口径**：`_is_hit` 恒以「上涨」为命中；对 `higher_bearish` 否决位应判「亮灯日跑输未亮日/基线」，否则会把「亮灯日涨得更多」当成有效性（klow2 六窗 lift>1 即此反例）。
3. **复核结论前**：crowd6 从生产否决位降为影子观察（不改冻结参数、不重训）；若不接受观察期，按 §5.2「无牌照=不入盘」直接移出。
4. **若继续积累证据**：预先注册「p_up>0.52 子集」为主检验，按 §B.7 预算（约 2.5~3 年）或扩资产池/扩市场重做。
5. 附带：klow2 的方向异常（p=0.010）建议单独立项。
