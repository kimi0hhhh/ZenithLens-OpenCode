## 0. 一句话

基金量化方向预测系统：用场内 ETF 日线预测持仓基金未来 T+1/T+3/T+15 的涨跌方向。
立身之本 = 可验证的预测（跑不赢基线自动灰显）+ 实时估值保真 + 诚实审计。
**独立重做，不与 FundLens（ZCode 版）共用任何代码。**

## 1. 背景

持有多只场外基金，每天需要「今天该不该动」的判断依据，而不是更多图表。
已有 FundLens（ZCode 版）在方法层验证了核心逻辑；本产品由 OpenCode 独立实现同一产品目标，
以对照两套编排的产出，并就近修复 FundLens 暴露过的启动/兼容问题。

## 2. 目标用户

用户本人。Windows 单用户、本地部署不联网、持 22 只场外基金、每天看一次。
既使用预测信号，也审计这套系统本身是否诚实。

## 3. 必须解决的核心问题

1. **方向判断**：对能预测的资产给出未来 N 天涨/跌方向 + 可信度；组合层给「组合加权 P + 覆盖市值占比」，覆盖不足必须显式声明。
2. **实时估值保真**：官方净值 / 盘中估算 / 重仓加权 / 代理近似 / 未知 五档降级链；来源徽章由后端真实驱动（不得静态硬编码）；**估值 ≠ 净值**，两者来源必须可区分、可追溯。
3. **可审计**：任何一次判断可回溯（凭什么、用的什么数据、历史上赢过多少次）；台账 INSERT-ONLY。

## 4. 明确的失败定义 ★

- **T+1 方向正确率不跑赢基线**（基线 = `max(恒涨, 恒跌)`，报增量 Δ）→ 产品无价值。
- **把「看起来能预测其实不能」的资产标为可信** → 比不做更糟。
- **数字错误**（收益率 / 市值 / 估值口径算错）→ 直接失败。
- **展示数字与后端 API 不一致**（口径分叉）→ 失败。
- **前端假数据填充**冒充真实输出 → 失败。
- Python 3.8+ 跑不起来 / exe 点「启动」无反应 → 交付失败。

## 5. 已知约束 ★

### 5.1 预测核心逻辑（必须实现；允许优化，但改动须过 5.2 方法论）

- **触发门**：E1 跳空 `low[t] > high[t-1]`；E3 无量急跌 `ret < -2% 且 vr < 0.8`。E2/E4 已证伪，禁止 OR 合并。
- **DDSM**：三维 `[r2, om, vr]` 各 5 档 = 125 状态格；加噪 `K=4`、`p=0.25`；收缩 `P=(n_up + 10×训练段涨率)/(n+10)`；`MIN_N=15`。
- **双否决**：拥挤度（六维复合 z，训练段最拥挤 40% 否决）+ KLOW2（下影线比，最不利 40% 否决）。
- **出口**：`P > 0.5 + BAND(0.02) = 0.52` 单向做多，**永不做空**。
- **基线** = `max(恒涨, 恒跌)`，报增量 Δ，不报裸命中率。
