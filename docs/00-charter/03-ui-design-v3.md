# R2 UI 设计升级文档 · 极境 ZenithLens

> 上游：`02-prd-v3.md`（F2-01..25）。R1 的 `03-ui-design.md`（v3）与 `04-ui-wireframe.html` **原样保留**，本文件只做**增量升级设计**。
> 线框：`04-ui-wireframe-v3.html`（在 R1 线框基础上增量升级，可打开自包含）。设计基准：`00-design-reference-legacy-v2.html`。
> **范围铁律**：7 Tab 结构不变；R-UI-01..40 一个不删；视觉语言（玻璃拟态 / 涨红跌绿 / 未知≠持平 / 隐私打码 / 估值来源徽章 / 四态）**不倒退**。

## 摘要

1. R2 UI = **12 项样式交互升级点（U-01..U-12）**，每项含「现状短板 → 具体改进点 → 可测验收」，拒绝「更好看」式空话。
2. 升级主轴：把**成绩位从「—」变出数**（U-01）、把**徽章从灰色问号变双信息层**（U-02）、把**四态从演示条变真实触发**（U-03）、把**回填态点亮**（U-04）。
3. 基准补课（对照 legacy v2 实测差距）：**sticky 表头**（legacy `th{position:sticky}`）、**焦点态**（legacy `input:focus`）、**折叠区 hover**——R1 缺失，R2 补齐（U-09/U-10）。
4. 四态逐页重定义**真实触发条件与文案**（§4）：空态必须回答「为什么空 + 下一步」，success 前不得渲染任何数字。
5. **不倒退对账**（§8）：40 组件逐一保留声明 + R2 触达升级的 16 个组件（15 行触点表，28/29 合行）升级触点表，供前端与 QA 双向核对。

## 正文

### 1. IA 与范围声明

- 信息架构**不变**：一个壳（Topbar / Sidebar / LiveBar）+ 7 Tab（持仓 / 分析 / 信号 / 因子 / 复盘 / 引擎 / 设置）+ 弹窗/气囊层（R1 `03-ui-design.md §1` 原样有效）。
- R2 不改导航、不改页面归属；所有升级为**页内增量**（数据填充、组件态、交互细节）。
- R-UI-01..40 的「组件名 / 所属页 / 四要素 / 验收 / P0」维持 R1 定义；R2 只**增益**，不删减、不降级。

### 2. 视觉规范增量（Design Tokens）

基础 tokens **不变**（`--canvas/--card/--stroke/--ink*/--up/--down/--gold`、圆角、玻璃 blur 26px、tabular-nums、3 blob）。

R2 新增/明确：

| 项 | 值 | 用途 |
|---|---|---|
| 来源档底色 `.vb.l1/.l2/.l3/.l0` | 绿 `.08` / 金 `.1` / 灰 `.1` / 虚线灰 `.05` | 徽章**第一层**：来源等级（对齐 legacy v2，R1 缺失） |
| 置信度描边 `.vb.ch/.cm/.cl/.cu` | 现有值不变 | 徽章**第二层**：回测置信度（误差达标/中等/偏大/无） |
| 焦点环 | `outline:2px solid var(--ink); outline-offset:2px`（`:focus-visible`） | 键盘可达（U-10） |
| sticky 表头 | `thead th{position:sticky;top:0;z-index:2;background:rgba(248,249,246,.94);backdrop-filter:blur(10px)}` | 长表滚动表头常驻（U-09） |
| 折叠 hover | `details.fold>summary:hover{background:rgba(255,255,255,.6)}` | 可点性反馈（U-10） |
| 动效纪律 | 仅 transition ≤.2s；尊重 `prefers-reduced-motion:reduce`（动画降级为静态） | 不炫技、不阻塞 |

**硬性视觉规则（沿用 R1 + R2 补充）**：
- 涨红跌绿、未知斜体灰、`—` ≠ `+0.00%`（**绝不渲染 `+0.00%`**）、隐私打码 `••••`。
- 徽章双层编码缺一不可：**来源底色（是什么） × 置信度描边（准不准）**，两维信息不得合并成一个颜色。
- 所有「未接通」处（成绩、基线、Δ）用**待填充**样式（`.flat` 灰 + 虚线下划线），**禁止**用 0 / 估计值 / 示例数填充。

### 3. 样式交互升级 12 项（U-01..U-12）

#### U-01 · 成绩位填充（复盘 hero / 三窗口 / 立方体对比卡 / 因子盘）
- **现状短板**：复盘 hero 与三窗口全「—」、逐笔对账全「待回填」、立方体对比卡走前 Δ 恒 null、因子页仅 2 个因子（解剖 §F2-1：结构对了但「成绩」缺席，观感是半成品仪表盘）。
- **改进点**：F2-11/12 接通后按真实数据渲染——hero（命中率 + 基线 + Δ 三段式）；三窗口表分行标注接通状态（T+1 出数 / T+3、T+15 未接通保持「待填充」）；立方体对比卡走前 Δ 出数；因子盘空位显示「（当前为空）」。全部**不许**出现示例数/估计值。
- **验收**：① hero 非「—」；② 三窗口 ≥T+1 行完整；③ 对比卡 Δ 非 null 或明确「等待 R2-11」；④ 「待填充」样式正确（负向断言：无估计值）。

#### U-02 · 置信度双层徽章 + 全口径 tooltip
- **现状短板**：22/22 全灰、tooltip 无 MAE/样本；且 R1 只有「置信度描边」一层，缺 legacy v2 的「来源档底色」（§F2-3、§F3；legacy `.vb.l1-l3`）。
- **改进点**：`.vb` 升级为双层编码；tooltip 组装 **7 项**：来源说明、降级链路 trace、MAE、方向命中率、样本数 n、回测窗（40 日）、披露口径（重仓时）；unknown 必须带原因（缺净值/缺估值/样本不足/待回填）；点击徽章展开当日逐次入账历史（R1 已有，保留）。
- **验收**：① hover 可见 ≥6 项字段；② 五档来源 × 四级置信度同屏可区分；③ unknown 有原因文案；④ 缺数据留白不编造。

#### U-03 · 四态全量接线（emptyWhen 真实触发）
- **现状短板**：OBS-03 遗留——空态仅演示条可触发；真实环境下七页恒 success（§F2-2）。
- **改进点**：逐页把空/加载/错误判定接到**真实数据条件**（§4 表）；空态文案含「为什么空 + 下一步」；错误态含「可读原因 + 重试」；加载态含骨架/脉冲 + 具体动作文案。
- **验收**：① 7/7 页可触发空态（QA 构造数据）；② 空态文案含两要素；③ error 可读 + 重试；④ empty 下不渲染数字行（断言）。

#### U-04 · 回填态激活（时间线 / 对账 / 事件链）
- **现状短板**：时间线圆点恒空心、对账恒「待回填」×320 条（§F2-1）。
- **改进点**：F2-12 回填接通后——`.tl-item.hit/.miss` 圆点着色；对账表判定列 hit/miss 徽章；事件链第⑥步从「待回填」变「命中/未命中 + 数值」；「待回填」只允许出现在未到期记录。
- **验收**：① hit/miss 与 t1_real 符号一致；② 未到期才显示待回填；③ 第⑥步出值；④ 刷新后一致。

#### U-05 · 影子盘进度真实化
- **现状短板**：进度条恒「0/60」且机制封顶 20（§C1）。
- **改进点**：按 F2-13 合并计算输出真实 x/60；进度条下方注明「归档合并计算」口径；idle/ok/bad 三态与阈值（60 日 + 偏差 >2pp）文案随状态切换。
- **验收**：① x/60 与后端一致；② 口径标注；③ 三态文案正确。

#### U-06 · 数据源健康升级
- **现状短板**：fail_count 544 误导、sina 永远 unchecked、断链源无说明（§D1/§D2）。
- **改进点**：失败计数口径改「近 7 日失败 n 次」（成功重置）；sina 行有实测三态 + 时间戳；持仓数据卡改「产品自持主源」口径；nav_history 滞后显示随 F2-16 更新（≤1 交易日显示正常态）；历史失败折叠可查。
- **验收**：① 五源均有状态与时间戳；② 计数为时间窗口口径；③ 断链/降级说明可读；④ 滞后 ≤1 交易日时显示正常态。

#### U-07 · C 档验证状态四态
- **现状短板**：「待验证」静态标签，无法区分「在验证」与「挂着不动」（§B2）。
- **改进点**：行内标签四态——待验证（灰）/ 验证中（批次号，金）/ 已验证（升 B + 日期，绿）/ 验证未通过（降级 + 原因，红）；tooltip 显示 tier_reason；升 B 后信号列同步。
- **验收**：① 7 只行内可见；② 状态 = 后端 tier_reason；③ 升 B 同步；④ 未通过有原因。

#### U-08 · QDII 领先口径标注
- **现状短板**：QDII 的信息优势（境内代理领先净值 1–2 天）全站看不见（§B4-4）。
- **改进点**：信号卡与持仓 QDII 行加标注 chip「QDII · 境内代理领先净值 1–2 天」，tooltip 解释口径；不改变任何信号逻辑。
- **验收**：① 信号卡与持仓行均出现；② 文案与 Brief §5.3 一致；③ 逻辑零变更（断言）。

#### U-09 · 长表 sticky 表头（基准补课）
- **现状短板**：R1 无 sticky；legacy v2 有 `th{position:sticky;top:0;z-index:2}`（§F3 对照）。
- **改进点**：全站表格（持仓明细 / 台账 / 对账 / 竞技场 / 因子跑分）表头 sticky + 半透明磨砂底；窄屏保底横向滚动（R1 已有 overflow 容器保留）。
- **验收**：① 长表滚动时表头常驻（Chrome/Edge）；② 表头背景不与行内容穿透混淆；③ 旧内核降级为普通表头不报错。

#### U-10 · 键盘与焦点（基准补课）
- **现状短板**：R1 无 `:focus-visible`；legacy v2 有 `input:focus`；dialog 无 Esc/焦点回位。
- **改进点**：全站可交互元件 `:focus-visible` 焦点环；dialog 支持 Esc 关闭 + 关闭后焦点回到触发元素；折叠区 summary hover 反馈；toast 用 `aria-live="polite"` 播报。
- **验收**：① Tab 可达主导航/按钮/表格行操作且焦点可见；② Esc 关闭任一 dialog；③ 焦点回位；④ `prefers-reduced-motion` 下无强动画。

#### U-11 · 数字口径悬浮统一
- **现状短板**：口径说明分布不均（部分数字有 title、部分无）。
- **改进点**：总资产/今日盈亏/累计收益/收益率/加权 P/覆盖占比/Δ/MAE/进度 等**关键数字统一** hover 显示口径 tooltip（分子分母/样本/窗口/来源）；文案从字典取（U-12）。
- **验收**：① 抽查 10 个关键数字均有口径 tooltip；② 文案与字典一致；③ tooltip 不含无来源数字。

#### U-12 · 文案字典纪律
- **现状短板**：「未知/—/待填充/待回填/不表态」在页面间使用不一致的风险（F-PM-01 教训，§E5）。
- **改进点**：字典入 §7；组件实现从字典文案取值（单一来源）；四层覆盖口径单页化（PRD §0）。
- **验收**：① 字典与线框一致；② 抽查 3 页 0 混用；③ 新增文案先入字典（review 清单项）。

### 4. 四态全量定义（真实触发条件 + 文案）

> 四态容器沿用 R1 `StateBlock`（`data-state=empty|loading|error|success`）。下表为 **R2 真实触发条件**（emptyWhen 落点）与空态文案要求。
> 铁律：success 前不渲染任何数字；error 不回退示例数据。

| 页 | 空态触发（真实条件） | 空态文案（为什么空 + 下一步） | 加载态 | 错误态 |
|---|---|---|---|---|
| 持仓 | 持仓列表为 0（不是「全部未知」） | 「还没有录入任何持仓」+ 数据源路径 + 「录入第一只基金」 | 四卡骨架 + 「正在读取持仓与估值…」 | 「读取持仓失败：<原因>」+ 重试 + 检查路径 |
| 分析 | 监控集合为空，或全部资产无预测记录 | 「今日没有触发开口的资产」+ 四要素事实卡 + 低频说明 | 三窗口脉冲 + 「正在计算三窗口预测…」 | 「预测服务暂不可用」+ 原因 + 重试 |
| 信号 | **两变体**：① 台账为空（从未记录）→「影子盘尚未开始记录」；② 有台账但窗口内无开口 → 「今日无信号」四要素 | 变体①给启动说明；变体②强调「这是常态，不是故障」 | 「正在读取信号台账…」 | 「读取信号台账失败」+ 原因 + 重试 |
| 因子 | 四盘均无因子 | 「因子库为空，等待首次扫描」+ 周提名说明 | 盘面骨架 | 「因子账本读取失败」+ 缺失文件名 |
| 复盘 | 回测未接通（无成绩文件或全窗口待填充） | 「尚无成绩记录，引擎未产出回测」+ 「待填充≠0」说明 | hero 脉冲 | 「读取成绩失败」+ 重试 |
| 引擎 | 引擎心跳缺失 | 「引擎离线」+ 最近成功时间 + 启动指引 | 「正在连接本地引擎…」 | 「引擎无响应」+ 错误码 + 重试 |
| 设置 | 数据源从未检测 | 「尚未检测数据源」+「立即检测」 | 行内「检测中…」 | 「配置读写失败」+ 原因（不丢已填） |

**组件级四态补充**（被 R2 升级触达）：U-02 徽章（状态不可用→「来源不可用」虚线、字段缺失→留白不编造）；U-05 进度（归档缺失→按主文件计算 + 口径降级标注）；U-07 验证标签（状态缺失→「待验证」兜底 + 标注）。

### 6. 响应式与可访问性

- 断点维持 R1：≥1100 侧栏常驻 / 900–1100 四卡两列 / ≤900 底部导航 + 单列 + 表格横向滚动。
- 可访问性增量（对齐 legacy 基准 + R2-23）：`:focus-visible` 焦点环；`aria-live` toast；dialog Esc + 焦点回位；对比度不降级；`prefers-reduced-motion` 降级动画。
- 屏幕阅读顺序：数字 → 口径 → 来源徽章 → 操作按钮（不因视觉装饰打乱 DOM 顺序）。

### 7. 文案字典 + 四层覆盖口径（单页化）

**文案字典（词 × 使用场景 × 禁止）**：

| 词 | 使用场景 | 禁止 |
|---|---|---|
| 未知 | 无任何可信估值来源（`pct=null`） | 渲染 `+0.00%`；与「待填充」混用 |
| — | 不适用 / 未到期 / 无记录 | 表示「计算失败」（失败要给原因） |
| 待填充 | 口径未接通（无成绩/无基线） | 填估计值、示例值、0 |
| 待回填 | 信号未到期（t1_real 未产生） | 出现在已到期记录上 |
| 不表态（灰） | 无边际/未开口（≠看平） | 按 0.5 计入组合加权 |
| 低样本 | MAE 样本 < 阈值 | 冒充「误差达标」 |
| 数据缺失 | 某步数值缺（链路中） | 留空不说明 |

**四层覆盖（单页口径）**：估值覆盖（`change_rate != null`）/ 预测覆盖（A/B universe）/ 开口覆盖（触发 E1/E3 资产数）/ 可信估值覆盖（置信度非 unknown）——四者**分列声明、禁止互替**（PRD §0 同步）。

- **R2 升级触点表**（被升级触达的 16 个组件、15 行（28/29 合行）；其余 24 个零变更）：

| 组件 | 升级内容 | 关联 |
|---|---|---|
| R-UI-02 vsum | 出数 + 原因 chip | U-02 |
| R-UI-03 徽章 | 双层编码 + 7 项 tooltip + unknown 原因 | U-02 |
| R-UI-06 风险折叠 | fold hover 反馈 | U-10 |
| R-UI-09 时间线 | hit/miss 圆点激活 | U-04 |
