## 摘要

1. 信息架构 = **一个壳 + 7 个 Tab**：持仓 / 分析 / 信号 / 因子 / 复盘 / 引擎 / 设置；导航固定于左侧栏（窄屏变为底部栏）。
2. 每个页面都定义 **空态 / 加载中 / 错误 / 成功** 四态；空态是真实用户第一眼最常看到的，因此按"正常设计稿"对待。
3. 命脉组件有三个：**估值来源徽章**（mode 驱动 + 降级链路）、**未知态渲染**（pct 空 → "未知"，绝不出 `+0.00%`）、**隐私打码**（金额位 → `••••`）。
4. 视觉 token 沿用 legacy v2 壳的克制风格：玻璃卡片、圆角 18px、`--up:#d93843` / `--down:#0e8a63`、等宽表格数字。
5. 交互原则：**只读观测优先**，危险操作二次确认；任何数字必须能下钻到口径。
6. **v2 核心**：R-UI-01..40 逐项给出组件规格（§7），覆盖 legacy v2 壳丢失的 83% 特调内容；线框必须含 125 格立方体、因子四盘+治理长文、估值徽章 `.vb`、推导链 `.chain-item`、竞技场矩阵、影子盘台账、六维 z-bar。
7. **v3 核心**：§8 给出 40 项 **R-UI ↔ 四态 ↔ 功能点 ↔ 用户故事 ↔ 视觉令牌** 追溯矩阵，前端可据此逐项自检"缺一即 G-FE-01 不通过"；本节不新增/删减任何组件，只做可核对化。

## 正文

### 1. 信息架构（IA）

```
极境 ZenithLens（单页外壳 single-shell）
│
├─ 顶栏 Topbar（全局）：日期 · 交易时段 · 数据快照/滞后提示 · 隐私开关 · 本次开口数
│
├─ 左栏 Sidebar（7 Tab，全局常驻）
│   ├─ ① 持仓 holdings   ← 默认首页：总览 + 估值精度 + 组合预测 + 覆盖度 + 明细
│   ├─ ② 分析 analyze    ← 口径定义 + 三窗口组合预测 + 参与预测明细 + 信号链路样例
│   ├─ ③ 信号 signals    ← 最新信号（空态为主）+ 触发条件 + 信号时间线
│   ├─ ④ 因子 factors    ← 四盘 + 四本账本 + 评分链 + 治理周期 + 挖掘记录 + 生命周期规则
│   ├─ ⑤ 复盘 review     ← 模型历史成绩 + 三窗口 vs 基线 + 实盘对照 + 逐笔对账
│   ├─ ⑥ 引擎 engine     ← HUD + 影子盘台账 + 竞技场 + 训练状态 + 冻结参数 + 六维输入 + 125 格
│   └─ ⑦ 设置 settings   ← 隐私 + LLM(shadow) + 数据源健康 + 引擎注册表 + 持仓数据 + 关于
│
└─ 弹窗层 Dialog：录入/编辑基金 · 加仓/减仓 · 删除确认
   └─ 气囊层 Popover：行操作菜单 · 显示列
```

**层级关系**：顶栏与侧栏为全局壳层；7 个 Tab 为平级视图（同一时刻仅一个 active）；弹窗/气囊为覆盖层，关闭后回到当前 Tab。**无二级页面跳转**——所有下钻通过"展开/折叠/弹窗"完成，保证单页不丢上下文。

**信息优先级**（决定每页第一屏放什么）：
1. 与我钱有关的数字（总资产/盈亏）— 持仓页最上。
2. 今天该不该动（组合预测/信号）— 持仓页与信号页。
3. 这个数可信吗（估值来源/覆盖度/基线）— 紧随其后。
4. 系统本身诚不诚实（台账/数据源/引擎）— 引擎、设置页。

### 2. 视觉规范（Design Tokens，参照 legacy v2 壳）

| Token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#f4f6f2` | 页面底色 |
| `--card` | `rgba(255,255,255,.58)` | 玻璃卡片 |
| `--stroke` | `rgba(255,255,255,.75)` | 玻璃描边 |
| `--ink / --ink2 / --ink3` | `#182019 / #7c857e / #a3aaa4` | 主/次/弱文字 |
| `--up` | `#d93843` | **涨（红）** |
| `--down` | `#0e8a63` | **跌（绿）** |
| `--gold` | `#c99700` | 警示/待验证/误差 |
| 圆角 | 卡片 18px / 小件 12~14px | 统一 |
| 玻璃 | `backdrop-filter: blur(26px) saturate(150%)` | 侧栏与卡片 |
| 数字 | 等宽 `tabular-nums` | 表格与指标，禁止比例数字错位 |
| 背景装饰 | 3 个模糊光斑 blob | 绿/桃/蓝，营造玻璃层次 |

**硬性视觉规则**：
- **涨红跌绿**：正数/上涨用 `--up`，负数/下跌用 `--down`，持平/未知用 `--ink2`。
- **未知 ≠ 持平**：未知用斜体灰 + 「未知」二字；`—` 用于今日盈亏未知；**绝不渲染 `+0.00%`**。
- **徽章色由置信度决定而非来源名**：置信度高/中/低/无 → 绿/金/红/虚线灰。
- **隐私打码**：金额位统一 `••••`，占比与涨跌百分比保留。
- 无深色主题（参照 legacy：引擎页也沿用极简玻璃，不另起深色）。

### 4. 关键页面与四态定义

> 约定：四态用统一 `StateBlock` 渲染。视觉上：空态=居中提示+事实卡；加载中=骨架/脉冲点+文案；错误=红色边框+可读原因+重试；成功=真实内容。

#### 4.1 持仓页 holdings（默认首页）

**页面结构**：Topbar → LiveBar → 资产总览四卡 → 估值精度汇总 → 组合预测三窗口 → 覆盖度四档 → 持仓明细表（可折叠分组）→ 风险指标（折叠，慢接口）。

**组件**：`StatCard×4`、`ValBadge`、`CoverageBar`、`ForecastWin×3`、`DataTable`、`FoldSection`。

| 状态 | 表现 |
|---|---|
| **空态** | 无持仓：`StateBlock` 显示"还没有录入任何持仓" + 引导按钮"录入第一只基金" + 数据源路径提示。 |
| **加载中** | 四卡显示 `—` 骨架 + 一个脉冲点 + 文案"正在读取持仓与估值…"；明细表显示 3 行骨架。 |
| **错误** | `Funding source` 读取失败：红色条"读取持仓失败：<可读原因>" + "重试"按钮 + "检查数据文件路径"链接；不清空已有数据（若有）。 |
| **成功** | 正常渲染：四卡数字、估值徽章、三窗口预测、覆盖度、明细表分组可折叠；未知行显示「未知」。 |

**关键交互**：点汇总卡 → 弹出口径说明；点明细行 `···` → 加仓/减仓/编辑/删除；点分组行 → 折叠；点"显示列" → 切换列；点"隐藏金额" → 打码。

#### 4.2 分析页 analyze

**页面结构**：口径定义（折叠）→ 三窗口组合预测 → 加权规则说明 → 参与本次预测的持仓表 → 单信号导出链路样例（折叠）。

| 状态 | 表现 |
|---|---|
| **空态** | 今日无任何资产开口："今日没有触发开口的资产" + 事实卡（监控中 N/M、距上次开口 X 天、上次开口与结果）。 |
| **加载中** | 三窗口卡显示脉冲占位"正在计算三窗口预测…"。 |
| **错误** | 预测服务不可用："预测服务暂不可用" + 可读原因 + 重试；已算出的历史成绩仍展示并标注时间。 |
| **成功** | 三窗口卡（加权 P + 覆盖占比）+ 明细表（档位/触发/P/否决/T+1/T+3/T+15/市值）+ 6 步链路可展开。 |

#### 4.3 信号页 signals

**页面结构**：最新信号卡（通常为空态）→ 触发条件（E1/E3）说明 → 信号时间线（60 天）。

| 状态 | 表现 |
|---|---|
| **空态** | "今日无信号" + 事实卡（监控中 N/M、距上次开口、上次开口基金、上次结果）；**这是常态，需写明不是故障**。 |
| **加载中** | 时间线显示脉冲骨架 + "正在读取台账…"。 |
| **错误** | 台账不可读："读取信号台账失败" + 可读原因 + 重试。 |
| **成功** | 信号卡（日期/基金/触发门/P/结果）+ 时间线（hit 红点 / miss 绿点 / veto 空心点），点击展开 6 步链路。 |

#### 4.4 因子页 factors

**页面结构**：四盘 → 四本账本 → 评分链 → 治理周期 → 最近挖掘记录 → 生命周期规则。

| 状态 | 表现 |
|---|---|
| **空态** | 尚无因子入盘："因子库为空，等待首次扫描" + 说明（周提名 ≤3）。 |
| **加载中** | 盘面骨架 + "正在读取因子账本…"。 |
| **错误** | 账本缺失："因子账本读取失败" + 缺失文件名 + 可读原因。 |
| **成功** | 四盘各含因子与角色；账本记录；评分链参数；生命周期规则文本。 |

#### 4.5 复盘页 review

**页面结构**：历史成绩 hero → 三窗口 vs 基线表 → 实盘对照（影子盘降级审查）→ 逐笔对账表。

| 状态 | 表现 |
|---|---|
| **空态** | 无回测成绩："尚无成绩记录，引擎未产出回测" + 说明。 |
| **加载中** | hero 显示脉冲占位"正在汇总历史成绩…"。 |
| **错误** | "读取成绩失败" + 可读原因 + 重试。 |
| **成功** | 命中率/基线/Δ 并列，Δ 着色；实盘对照与回测可区分；逐笔对账含 t1_real 判定。 |

#### 4.6 引擎页 engine

**页面结构**：HUD → 影子盘台账状态与最近记录 → 因子竞技场 → 训练状态与冻结参数 → 六维输入 → 125 格离散对比。

| 状态 | 表现 |
|---|---|
| **空态** | 引擎未运行："引擎离线" + 最近成功时间 + 启动指引。 |
| **加载中** | HUD 脉冲点 + "正在连接本地引擎…"（Topbar 下方的 LiveBar 同步）。 |
| **错误** | 引擎心跳失败："引擎无响应" + 错误码/原因 + 重试；已缓存只读数据仍可看。 |
| **成功** | 各只读面板渲染：HUD 在线脉冲、台账最近记录、竞技场矩阵、冻结参数、六维 z-bar、125 格热力。 |

#### 4.7 设置页 settings

**页面结构**：隐私 → LLM（shadow）→ 数据源健康 → 引擎注册表 → 持仓数据 → 关于。

| 状态 | 表现 |
|---|---|
| **空态** | 数据源未检测："尚未检测数据源" + "立即检测"按钮。 |
| **加载中** | 数据源行显示"检测中…"脉冲。 |
| **错误** | 配置读写失败："保存配置失败" + 可读原因；不丢失已填内容。 |
| **成功** | 隐私开关（打码生效）、LLM 配置（标注 shadow）、数据源三态、引擎注册表（active/shadow/retired）、持仓数据信息、关于（本地存储/免责）。 |

### 5. 关键组件细规

#### 5.1 估值来源徽章 ValBadge（命脉组件）
- 文案：`官方净值 / 盘中估算 / 重仓加权 / 代理近似 / 未知`。
- 配色：按置信度（回测 MAE 对照行业基准 0.80%）→ 高绿 / 中金 / 低红 / 无虚线灰；来源名与置信度**分离**，置信度优先着色。
- 详情（悬浮/展开）：来源说明 + 降级链路（如 `official 未出 → intraday 命中`）+ 历史 MAE + 方向命中率 + 样本日数。
- 硬规则：文案必须来自后端 `mode` 字段；无链路数据时不编造。

#### 5.2 未知态 UnknownCell（命脉组件）
- `pct` 为空：涨跌列渲染 `<span class="unk">未知</span>`（斜体灰）。
- 今日盈亏：`—`。
- 汇总：标注"仅覆盖 N/M 只，其余未知不计入"。
- 禁止：`Number(null)`、`Number(undefined)`、空字符串参与 `+0.00%` 计算。

#### 5.3 隐私打码 PrivacyMask
- 开关开启：`.amt` 类金额位全部替换为 `••••`。
- 百分比/占比不遮。
- 状态本地持久化。

#### 5.4 四态 StateBlock（全局）
- `data-state="empty|loading|error|success"` 切换。
- empty：居中标题 + 副文案 + 可选事实卡/行动按钮。
- loading：脉冲点/骨架 + 文案。
- error：红色边框 + 标题 + 可读原因 + 重试。
- success：渲染真实内容。
- **铁律**：任何页面在 `success` 前不得显示伪造数字；`error` 下不得回退到示例数据。

### 6. 响应式与可访问性

- ≥1100px：侧栏 248px 常驻，四卡一行。
- 900~1100px：四卡两列。
- ≤900px：侧栏转底部导航栏，四卡/表格单列，主区底部留白避免遮挡。
- 可访问性：涨跌不**仅**靠颜色区分（附 +/− 号与「未知」文字）；徽章有 title/可读文本；对比度满足正文可读。

## 7. 特调组件逐项规格（v2 新增 · 对应 R-UI-01..40）

> 本节是 `02-prd.md` §2.5 的 UI 侧落地。每项四行：**数据来源字段 / 四态 / 交互 / 视觉令牌**。
> 四项缺一即该项不达标；40 项与 Brief §9 一一对应，缺一即 G-FE-01 不通过。
> **视觉令牌总表**（全部在 §2 已定义，此处集中引用）：`.vb` 估值徽章（五档 + `.ch/.cm/.cl/.cu` 置信度）、`.vsum` 估值汇总、`.covbar` 覆盖度、`.tl/.tl-item/.sigcard/.ev` 信号时间线、`.chain/.chain-item` 推导链、`.cube/.cc` 状态立方体、arena 红绿蓝黄配色（`.up/.down/--ink2/--gold`）、`.zbar` z 条、`.hud-c` HUD 卡、`.lcard` 引擎卡、`.frow/.fdet` 因子行/明细、`.dim` 六维行、`.prg` 进度条、`.degrade.idle/.ok/.bad` 降级条、`dialog/.dlg`、`.pop`、`#toast`、`.livebar.ok/.warn`、`StateBlock[data-state]`。

### 7.1 持仓页

#### R-UI-01 · 资产总览四卡
- **数据来源字段**：`holdings[].shares/cost/est/nav/pct/mode`；汇总 `total_assets / today_pnl / cum_pnl / return_pct / coverage{n,t}`（口径同 F-01）。
- **四态**：空＝「还没有录入任何持仓」＋「录入第一只基金」CTA＋数据源路径；加载＝四卡 `—` 骨架＋脉冲点＋「正在读取持仓与估值…」；错误＝红边「读取持仓失败：<可读原因>」＋重试＋检查路径；成功＝四卡数字＋口径副标题＋「覆盖 N/M 只」。
- **交互**：点卡展开口径说明；未知持仓→副标题红字「仅覆盖 N/M 只，其余不计入」；隐私开关联动 `.amt` 打码。
- **视觉令牌**：`.sc`（四卡）`.sc .v`（26px 等宽）`.amt`（打码目标）`.cov-warn`（覆盖不足红字）；色 `--up/--down/--ink3`。

#### R-UI-02 · 估值精度汇总条
- **数据来源字段**：`holdings[].mae / dir / n_test / confidence / market_value`；基准常量 `0.80%`（来源：深圳证监局抽查口径）。

#### R-UI-34 · 数据源健康表

- **四态**：空＝「尚未检测」＋「立即检测」；加载＝行内「检测中…」脉冲；错误＝「检测失败」＋重试；成功＝行列表。

- **视觉令牌**：`.kv`；`.tag.ok/.warn/.red`；时间戳/失败数 `.mono`；失败数 `--up`。

- **交互**：「重新导入」按钮＋确认；长文可复制路径；悬停显示差异明细。
- **视觉令牌**：`.card`＋`.kv`；路径 `.mono`；长文 `.mini`；差异百分比 `--gold`。

#### R-UI-36 · 关于卡

- **四态**：说明型。
- **交互**：无（只读）。

### 7.8 交互与状态

#### R-UI-37 · 三个 dialog + 行菜单 popover + toast
- **数据来源字段**：表单字段 `code/name/amount/shares/cost/confirm_days(T+1|T+2|T+3)`；行操作 `buy/sell/edit/delete`。
- **四态**：空/加载/错误/成功不适用（交互层）；校验失败→toast 拒绝。
- **交互**：录入/编辑 dialog（代码 6 位、名称必填、金额或份额至少一项、确认天数）；加仓/减仓 dialog；删除确认 dialog（二次确认）；行菜单 popover（加仓/减仓/编辑/删除）；toast 轻提示 2.2s。
- **视觉令牌**：`dialog/.dlg/.field/.row2/.dlg-acts`；`.pop/.pop button(.danger)`；`#toast(.show)`。

#### R-UI-38 · 注销 Service Worker
- **数据来源字段**：`navigator.serviceWorker` / `caches`。
- **四态**：不适用；无 SW 环境→try/catch 静默。
- **交互**：页面加载即执行（无 UI）。
- **视觉令牌**：无（脚本层）。

#### R-UI-39 · 真实数据接入条 livebar
- **数据来源字段**：`LIVE{holdings,predict,models,navDate}`；API 接入结果；滞后天数。
- **四态**：空＝未检测；加载＝「正在连接本地引擎…」（warn）；错误＝接口失败保留内置数据（不白屏）；成功＝ok「已接入本地引擎·持仓/预测真实」。
- **交互**：点条展开接入明细；快照日期联动侧栏滞后提示。
- **视觉令牌**：`.livebar.ok/.warn`；`.dot`（状态点）；`.chip.warn`（滞后）。

#### R-UI-40 · 四态覆盖
- **数据来源字段**：各页 `PAGE_STATE[view]`（`empty|loading|error|success`）。
- **四态**：本节即四态本体——`StateBlock` 统一渲染。
- **交互**：四态演示条切换（线框内）；错误态「重试」回到 success。
- **视觉令牌**：`.state-block[data-slot]`；`.state-block.error .inner`（红边）；`.pulse`（脉冲点）；`.skeleton`（骨架）；`.sbtn`（行动按钮）；铁律：success 前不得显示伪造数字、error 下不得回退示例数据。
