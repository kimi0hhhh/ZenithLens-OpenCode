# R2 升级功能文档 PRD · 极境 ZenithLens

> 上游：`01-requirements-v3.md`（R2 需求 25 条）；基线：`02-prd.md`（R1，F-01..F-17 + R-UI-01..40 **全部保留不删**）。
> 本文件只描述「要什么效果」，不指定框架/库/存储；算法与结构细节留 S2 架构师裁定（标注「待架构裁定」）。
> 每个功能点含 `输入 / 处理 / 输出 / 异常` 四要素；优先级仅 P0/P1/P2；验收锚定解剖基线值 → R2 目标值。
> 设计/线框配套：`03-ui-design-v3.md` / `04-ui-wireframe-v3.html`。

## 摘要

1. 本 PRD 定义 **25 个升级功能点**（F2-01..F2-25），一一对应需求 R2-01..R2-25；P0 = 12 / P1 = 12 / P2 = 1。
2. 三条升级命脉：**置信度误差通道**（F2-01，激活全站徽章与 vsum）、**回测接通 + 回填接通**（F2-11/12，Δ 出数）、**C→B 验证批次**（F2-06，覆盖扩容）。
3. 四层覆盖口径**单页化**（估值/预测/开口/可信估值），防再出 F-PM-01 类混用；文案字典（未知/—/待填充/待回填/不表态）同页落地。
4. **不做清单 15 条**：冻结纪律（E2/E4 禁复活、冻结参数改动须走六关）、边界（多用户/云端/实盘交易）、用户点名不做（历史记录类新功能 / Docker / 局域网）。
5. 所有验收可测量（百分比 / 只数 / 条数 / 字段名 / 断言）；未接通处一律「待填充」，**禁止估计值**。
6. R1 的 40 项特调组件与四态定义**一个不删**；R2 只做增量升级（样式交互 12 项，见 `03-ui-design-v3.md §3`）。
7. 本 PRD 用 `pre-mortem` 预演 R2 上线失败（§6）并登记 launch-blocking 处置（Owner + 期限）。

## 正文

### 0. 术语与口径（R2 单页化 · 含四层覆盖）

| 术语 | 定义 | 来源/落点 |
|---|---|---|
| **估值覆盖** | 当日 `change_rate != null`（五档链任一命中）的持仓只数 | 当前 22/22（§E5） |
| **预测覆盖** | 进入预测 universe（A/B 档）的只数 | 当前 15/22；R2 目标=7/7 结论 + 按实计（F2-06） |
| **开口覆盖** | 滚动窗口内实际触发 E1/E3 的资产数/行次 | 当前 11 资产/13 日/32 行次（§B1） |
| **可信估值覆盖** | 置信度非 unknown 的只数 | 当前 0/22 → 目标 ≥21/22（F2-01） |
| **Δ** | `命中率 − max(恒涨,恒跌)`（同期基线，实测口径） | 当前无值 → R2 出数（F2-11/14） |
| **待填充** | 口径未接通，**不填估计值** | F2-11 |
| **待回填** | 信号未到期，t1_real 未产生 | F2-12 |
| **不表态** | 未开口/灰，组合加权时从分子分母同时剔除（≠0.5） | R1 口径保留 |

**文案字典（词 × 场景 × 禁止）**：未知=无数据（禁止渲染 `+0.00%`）；—=不适用/未到期（禁止与「待填充」混用）；待填充=口径未接通（禁止填估计值）；待回填=未到期；不表态=无边际/未开口（≠看平）。
**四层覆盖口径**必须分列声明，**禁止互相替代**（估值覆盖 ≠ 预测覆盖，§E5 F-PM-01 教训）。

### 2. 功能详述（输入 / 处理 / 输出 / 异常）

#### F2-01 · 置信度误差通道（P0 · 核心）
- **输入**：valuation_history 逐日估值记录（`mode|code`）；T+1 官方净值（由 F2-16 回补）；accuracy 既有 proxy 口径数据。
- **处理**：当日估值入账 → 净值公布后回算当日误差（估值涨跌 vs 净值涨跌）→ 按 `mode|code` 键逐日累计 MAE 与方向命中率 → 滚动 40 日窗；置信度分档（误差达标/中等/偏大/无）由后端生成，前端只消费。
- **输出**：每只每档 `{conf, mae_rate, dir_hit_rate, n_test, window, reason}`；vsum 市值加权 MAE；徽章置信度配色（F2-20）。
- **异常**：净值未出 → 该日不回算（不填 0）；无法计算 → `conf=unknown` 且**必须带 reason**（缺净值/缺估值/样本不足）；单只样本 <5 → 显示「样本不足」不冒充达标。
- **验收**：① 置信度非 unknown ≥**21/22**（基线 0/22）；② vsum 加权 MAE 由 null → 非 null 且可复算；③ 24h 内产生当日误差记录；④ 下钻含 MAE/n/方向命中率/回测窗四字段。**（待架构裁定：误差回算落盘位置与增量重算代价）**

#### F2-02 · 重仓加权升级（P1）
- **输入**：F10 持仓（topline=20）；腾讯实时（A 股 + 港股）；美股标的可得性评估。
- **处理**：前 10 → 前 20 持仓；港股纳入实时；美股不可得时剔除并计入覆盖缺口；披露截止日与覆盖权重随记录。
- **输出**：holdings 档估值 + tooltip「披露截止日 / 覆盖权重 / 纳入标的数」。
- **异常**：F10 不可得 → 回退 proxy（保留原 no_report 语义）；单标的 null → 剔除不编造。
- **验收**：① tooltip 显示披露口径；② 5 只主动基金覆盖权重目标 ≥+10pp（或出不可得结论）；③ 无编造值（断言）。**（待架构裁定：两只 F10 解析器合并方案，技术债 T-05）**

#### F2-03 · QDII 时差校正（P1）
- **输入**：境内代理 ETF T 日收盘；隔夜美股/港股收盘（T−1→T）；汇率因素（可得时）。
- **处理**：双段估算——境内 ETF T 日涨跌 + 隔夜修正项（算法待架构裁定）；校正标志随估值记录。
- **输出**：QDII 估值 + tooltip 校正口径说明。
- **异常**：隔夜数据缺失 → 回退单段并在 tooltip 标注「单段（隔夜数据缺失）」；不得静默。
- **验收**：① 024239 ≤1.50%（基线 2.19%）、457001/021662 ≤1.00%（基线 1.23%）；② 不达标出「回退单段 + 原因」结论；③ 口径 tooltip 可见。

#### F2-04 · 代理复核批次（P1）
- **输入**：9 只超标代理清单；factor_engine 六窗走前能力；现行 tier/代理映射。
- **处理**：逐只跑六窗走前验证 → 定结论（保留/换代理/降档）→ 落盘验证记录 + 更新 tier/tier_reason。
- **输出**：9 只结论表（六窗 lift、MAE、方向命中率、样本、结论）；明示降档的可视化（F2-24）。
- **异常**：代理候选缺失 → 结论标记「无候选，明示降档」；不得留白。
- **验收**：① 9/9 出结论；② 025857/163208/014320 不得「超标且无结论」；③ 降档回填 tier_reason 且覆盖面板可见。

#### F2-05 · 估值历史跨日留存（P0）
- **输入**：每日估值记录（valuation_history 增量）。
- **处理**：每日收盘归档一个快照日；按 `mode|code` 收敛；滚动 ≥40 交易日；追加写语义。
- **输出**：≥40 日可查询的估值快照集；跨日偏差报表数据。
- **异常**：某日无记录 → 报表显示缺失日清单（不补造）；归档目录不可写 → 启动告警。
- **验收**：① 每交易日 1 快照日；② 可查滚动 ≥40 日（不足显示累计 X/40）；③ 可复算 MAE 序列；④ INSERT-ONLY（追加/可归档/不可改）。

#### F2-06 · C→B 走前验证批次（P0 · 核心）
- **输入**：C 档 7 只（022485/025500/018957/021528/457001/021662/163208）；代理 ETF 日线缓存（已有）；21-factor-governance 六窗机制。
- **处理**：逐只跑六窗走前 → 判定（lift≥1.0 且 Δ≥0 → 升 B）→ 更新 tier/tier_reason → 升 B 者入预测 universe。
- **输出**：验证结论表（7 行）；覆盖面板显示 `15/22（+7 待结论）` → 结论后按实计 `(15+k)/22`；行内验证四态（F2-24）。
- **异常**：数据不足的资产 → 结论「数据不足，维持 C + 复查日」；验证不通过 → 降 D + 原因；**禁止**「挂着 C 不给结论」。
- **验收**：① **7/7 出结论**；② 覆盖按实计展示（不承诺 22/22）；③ 升 B 资产 60 交易日内 ≥1 条台账记录或注明低频；④ 证据可复核。

#### F2-07 · 影子盘档位重算（P1）
- **输入**：shadow_signals 主文件 + 归档；现行 holdings 档位。
- **处理**：rolling_shadow_backfill 幂等重跑，按现档位重生成滚动窗；旧记录归档。
- **输出**：口径一致的台账；022485 记录与现 C 档口径对齐。
- **异常**：重算中断 → 事务性保护（重跑覆盖，不半写）；归档不可写 → 中止并告警。
- **验收**：① 档位一致性检查 0 冲突；② 幂等（重复执行结果不变）；③ INSERT-ONLY 纪律不破。

#### F2-08 · 开口低频期望管理（P1）
- **输入**：台账开口统计；监控集合；最近开口记录。
- **处理**：空态组装四要素 + 低频基线说明；统计口径改为「滚动 20 交易日开口资产数」。
- **输出**：信号页空态（常态说明）；监控指标（滚动 20 日开口资产数）。
- **异常**：台账空 → 要素显示「无记录」；监控集合空 → 「0/0」。
- **验收**：① 四要素齐全；② 文案含低频说明；③ 滚动 20 交易日开口资产数 ≥11（基线）；④ 升 B 后 60 日开口资产-日 ≥42。

#### F2-09 · QDII 领先口径标注（P1）
- **输入**：QDII 资产清单与信号/持仓数据。
- **处理**：信号卡与持仓行加「境内代理领先净值 1–2 天」标注（文案层）。
- **输出**：标注文案。
- **异常**：文案字段缺失 → 不显示（不编造）。
- **验收**：① 3 只 QDII 代理出现标注；② 口径与 Brief §5.3 一致；③ 不改变信号逻辑（断言）。

#### F2-10 · 出口灵敏度研究项（P2）
- **输入**：台账开口 32 次样本；走前 CV 机制。
- **处理**：研究 BAND 0.02→0.01 与分位微调的走前 Δ；产出报告进 21-factor-governance；不动冻结参数。
- **输出**：研究报告（六窗 + placebo）。
- **异常**：样本不足 → 报告标注「研究性，样本不足，不构成变更建议」。
- **验收**：① 报告落盘；② frozen_params 无 diff（断言）；③ 改参建议附六关提案。

#### F2-11 · 回测接通复盘页（P0 · 核心）
- **输入**：生产配置（gate + DDSM + 双否决 + 出口）作为 builtin 因子；factor_engine.evaluate；台账 universe（实测基线，F2-14）。
- **处理**：跑六窗走前 → 结果回填 /review/scores（hero + 三窗口，data_kind=backtest）→ 同页展示口径（走前 CV / purge=H+2 / placebo≥2pp / holdout 60）。
- **输出**：`{hit_rate, baseline, delta, n, method, windows{T1,T3,T15}}`；hero 与三窗口表出数。
- **异常**：窗口未接通 → 「待填充」（**禁止估计值**）；样本不足 → 标注样本数与「样本不足」；实盘不足 → 不拿回测冒充实盘。
- **验收**：① 由全 null → 至少 T+1 非 null；② Δ 可复算；③ 口径同页可见且与 cv-config 一致；④ 硬编码 null 清除（grep 验证）；⑤ 回测/实盘视觉可区分。

#### F2-12 · t1_real 自动回填（P0 · 核心）
- **输入**：已到期台账信号；代理日线（T+1）；回填口径（待架构裁定：代理涨跌 vs 净值涨跌）。
- **处理**：到期自动计算实际涨跌 → 写**独立** backfill.jsonl → 更新对账/时间线展示。
- **输出**：`t1_real / hit`；逐笔对账 hit/miss；时间线圆点状态。
- **异常**：标的日线缺失 → 标记「数据缺失待补」，不回滚已写；无对应 signal → 拒绝写入（维持契约）。
- **验收**：① backfill 0 → ≥1 条真实回填；② 已到期 up 回填 100%（≥4/4）；③ 只写 `t*_real`；④ 可复算；⑤ 口径页面注明。

#### F2-13 · 20/60 矛盾解除（P0）
- **输入**：shadow_signals 主文件 + archive；SHADOW_WINDOW_DAYS / TARGET_DAYS 机制。
- **处理**：连续记录天数按「归档 + 主文件」合并计算（或调整保留策略，待架构裁定）→ shadow_progress 输出真实值 → UI 进度条真实化。
- **输出**：`consecutive_days`（可达 60）；进度条 x/60（口径标注「归档合并」）。
- **异常**：归档缺失 → 按主文件计算并标注口径降级；不伪造天数。
- **验收**：① 可达 ≥60（可证）；② UI 与后端一致；③ 口径标注；④ 归档重建回归用例。

#### F2-14 · 基线实测化（P0）
- **输入**：台账 universe（全部资产-日）；现行 0.5830 常量。
- **处理**：实测 `max(恒涨率, 恒跌率)` → 替换硬编码 → 用于复盘 Δ 与影子盘偏差评估 → 进冻结参数表。
- **输出**：实测基线值 + 口径说明（universe、样本期）。
- **异常**：样本不足 → 标注「样本不足」并保留待填充；不得回退硬编码。
- **验收**：① 0.5830 不再参与计算；② 基线可复核；③ Δ 可复算；④ 进冻结参数表。

#### F2-15 · 持仓主源切换（P1）
- **输入**：data/holdings.json（现自持主源）；桌面源状态（断链）；导入能力（CSV/手工）。
- **处理**：主源声明切换；设置页文案与按钮口径更新；源缺失时按钮禁用 + 说明。
- **输出**：设置页「产品自持主源 · 正常」状态；导入按钮的行为与说明。
- **异常**：holdings.json 缺失 → 启动引导导入（可读提示，非 E_IO 堆栈）；写盘失败 → 原文件不破坏（原子写）。
- **验收**：① 无 `primary_exists=false` 误导展示；② 源缺失时按钮禁用 + 可读说明；③ 重启 22 只完整；④ 文案与边界声明一致。

#### F2-16 · nav_history 自动维护与新鲜度（P0）
- **输入**：lsjz 历史净值接口；nav_history 现状（滞后 18 天）。
- **处理**：每日任务增量补全 nav_history → 幂等；滞后天数计算同步到 UI。
- **输出**：nav_history 最新；滞后 ≤1 交易日；build_accuracy 样本 n_test。
- **异常**：接口失败 → 保留已有数据 + 标注滞后（不编造净值）；重复补全 → 幂等去重。
- **验收**：① 滞后 ≤1 交易日（基线 18 天）；② n_test ≥40（基线 7）；③ 幂等；④ 侧栏滞后显示真实。

#### F2-17 · 新浪源定案（P1）
- **输入**：sina_rt_quote（已实现未接线）；腾讯实时失败场景。
- **处理**：方案 (a) 接入为第二源（腾讯失败回退）/ 方案 (b) 枚举降级说明——二选一。
- **输出**：健康表新浪行实测记录；回退路径（若 a）或文案说明（若 b）。
- **异常**：新浪失败 → 静默回退腾讯/既有源（不阻塞估值链）。
- **验收**：① 健康表有实测三态 + 时间戳；② 方案与实现一致；③ 决策落盘。

#### F2-18 · fail_count 衰减/重置（P1）
- **输入**：health.json 失败计数（历史 544）。
- **处理**：成功后重置或时间窗衰减（近 7 日）；历史可折叠查看。
- **输出**：健康页计数口径（近 7 日失败 n 次）；历史折叠区。
- **异常**：无记录 → 「未检测」；时钟异常 → 以服务时间戳为准。
- **验收**：① 544 不再作为当前状态；② 成功 ≥1 次后衰减（断言）；③ 历史可查。

#### F2-19 · 成绩位填充（P0 · UI）

- **处理**：按真实数据渲染 hero / 三窗口 / 对比卡 / 因子盘。
- **输出**：出数的成绩位（或「待填充」纪律态）。
- **异常**：数据未接通 → 「待填充」（**不得填估计值**）；部分接通 → 分窗口独立标注。
- **验收**：① hero 出数；② 三窗口 T+1 行完整；③ 对比卡走前 Δ 由恒 null → 出数或明确等待标注；④ 文案保留。

#### F2-20 · 置信度解释层（P0 · UI）

#### F2-21 · 四态全量接线（P0 · UI）

- **验收**：① sticky 生效；② Tab 可达且焦点可见；③ Esc 可关 dialog；④ 三处基准（sticky/focus/fold-hover）不缺失。

### 4. 不做清单（R2 · 15 条）

> 范围控制比功能清单更能决定交付。以下含**冻结纪律**与**用户点名不做**。

1. **不做多用户**：无注册/登录/权限体系，单用户本机（Brief §7）。
2. **不做云端同步**：无服务器、无跨设备同步。
3. **不做实盘交易**：不接券商/交易接口，只给判断依据（Brief §7）。
4. **不做 E2/E4 复活、禁止 OR 合并**：E2/E4 已证伪，门只用 E1/E3（Brief §5.1 冻结纪律）。
5. **不做冻结参数的直接改动**：BAND / 双否决分位 / 加噪 / MIN_N / 窗口等任何调整**须走方法论六关**（走前 CV + purge=H+2 + placebo≥2pp + holdout 60 + INSERT-ONLY）；R2 只出研究项（F2-10），不承诺变更。
6. **不做历史记录类新功能模块**：台账 / 归档 / 估值历史 / 回填属**审计数据留存**，不是新增「历史记录」产品功能（用户点名不做）。
7. **不做 Docker 打包**：交付形态维持 `python app.py` + 桌面 exe（用户点名不做）。
8. **不做局域网多机访问**：绑 127.0.0.1，单机访问（用户点名不做）。
9. **不做深色主题**：维持 legacy 基准浅色玻璃拟态（R1 边界）。
10. **不做移动端 App**：本地 web + 桌面 exe（Brief §7）。
11. **不做 LLM 参与最终预测**：仅事件编码且停 shadow（Brief §5.5）。
12. **不做随机切分回测**：一律走前时序 CV（Brief §5.2）。
13. **不做全市场历史回补**：只维护持仓 universe 及其代理（F2-16 范围）。
14. **不做自动推送**：不接短信/微信/邮件（R1 边界）。
15. **不做覆盖虚报**：验证不通过的资产**明示降档**，绝不用「挂着 C 档」冒充覆盖（Brief §8）。
