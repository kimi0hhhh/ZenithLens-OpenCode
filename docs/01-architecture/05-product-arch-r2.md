# 产品功能架构 · 极境 ZenithLens（R2 升级轮增量）

> 本文是 `05-product-arch.md`（R1 v3）的**增量版本**：只写 R2 升级对**用户可见能力**的影响（四目标 + 前端升级），未变部分（9 大能力域、52 能力节点、术语裁定 §0、数据流硬规则）**沿用 R1 v3，不重抄**。
> 不确定性等级仍按三角色定义：**确定** = 依据充分/口径已冻结；**待验证** = 方向明确、参数/数据源/口径需实测或会签；**未知** = 当前无法给出可执行口径。
> 上游：`01-requirements-v3.md`（R2-01..25）、`02-prd-v3.md`（F2-01..25）、`03-ui-design-v3.md`（U-01..U-12）、`00-dissection-v3.md`。

## 摘要

1. 9 个能力域与 52 个能力节点**全部保留**；R2 在既有域内**新增/升级 21 个能力节点**（不新增域、不改域归属）。
2. 四目标对应四组能力变更：**估值更准**（误差通道/双段校正/前20/跨日留存）、**覆盖更多**（验证批次/重算/低频口径/验证可见）、**准确率更高**（回填激活/成绩出数/基线实测/进度真实化）、**来源可靠**（净值史/主源声明/兜底接线/失败窗口）。
3. 不确定性显式标注：R2 新增节点中 **确定 12 / 待验证 8 / 未知 1**（QDII 隔夜参照源的可用性——以"回退单段"对冲，见 §2）。
4. 术语不变；新增两个能力语义钉子：**「验证」四态**（待验证/验证中/已验证/验证未通过）与**「回填」口径**（代理日线，区别于估值误差通道的净值口径）。
5. 「本期不做」增量 4 条：不做净值口径回填、不做自动换代理决策、不做冻结参数改动、不做估算补缺。

## 正文

### 0. 术语补充（承接 v3 §0；不改既有词）

| 规范术语 | 定义 | Avoid |
|---|---|---|
| **验证** `verify`（R2） | 对 C 档代理映射做走前可信性判定并给结论的过程/状态；四态 = 待验证/验证中/已验证/验证未通过 | 检查、验收（系统级）、评估 |
| **回填** `backfill`（口径钉死） | 到期信号按**代理日线涨跌**写 `t*_real` 的动作；与「估值误差通道」（净值口径）**分属两条线** | 对账（对账=读回填后结果）、净值复核 |
| **可信估值覆盖** | 置信度非 unknown 的只数（承 v3 四层覆盖口径） | 预测覆盖 |

### 4. 能力域关键数据流增量（用户视角）

```
⑧ 净值史维护 ──对账──▶ ⑤ 误差通道（② 徽章置信度 / vsum）
⑧ 代理日线 ──回填──▶ ⑤ 台账回填（hit/miss）──成绩──▶ ⑤ 成绩出数（hero/三窗口）
③ 验证批次 ──结论──▶ 覆盖数据（④）──行内四态──▶ ③/①
⑤ 实测基线 ──▶ ⑦ 降级审查 / 影子盘
① 持仓行 ◀── qdii_lead_note / verify_status / trace.detail（披露口径）

硬规则不变：⑧ 是唯一数据入口；①~⑦ 一律经后端 API 取数，前端不得跨域自造（PRD G3）。
```

### 5. 本期不做（能力视角增量，与 PRD §4 对齐）

| 不做能力 | 理由 | 来源 |
|---|---|---|
| 净值口径的 t*_real 回填（本期） | 与预测锚点一致性 + 可得性；净值口径属估值通道（误差通道） | ADR-0008 |
| 自动换代理决策 | 换代理须人工确认映射 + 重跑验证批次；系统不自动改映射 | R2-04 纪律 |
| 冻结参数直接改动（含 BAND 灵敏度） | 六关纪律；R2 只出研究项 | Brief §5.2 / R2-10 |
| 估算补缺（样本不足填估计值/未知填 0） | 诚实纪律：null/原因，不编造 | Brief §8 |
| 多用户/云端/实盘/做空/OR 合并/深色 | 沿用 R1 v3 不做清单 | Brief §7 / §5.1 |
| 全市场净值史 / 全市场回补 | 只维护持仓 universe | PRD §4-13 |
