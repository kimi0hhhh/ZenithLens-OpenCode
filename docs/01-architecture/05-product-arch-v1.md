# 产品功能架构 · 极境 ZenithLens

> 上游：`docs/PROJECT_BRIEF.md`、`docs/00-charter/01-requirements.md`、`docs/00-charter/02-prd.md`、`docs/00-charter/03-ui-design.md`、`docs/00-charter/04-ui-wireframe.html`。
> 本文按**用户可见的能力域**分层（不是技术分层）。每个能力节点标注：`依赖上游` + `不确定性等级`。
> 不确定性等级定义：**确定** = 依据充分、口径已冻结；**待验证** = 方向明确但参数/数据源/口径需实测或会签；**未知** = 当前无法给出可执行口径。

## 摘要

1. 产品能力收敛为 **9 个能力域**：持仓总览 / 实时估值 / 方向预测 / 组合决策 / 复盘审计 / 因子治理 / 引擎观测 / 数据接入 / 系统设置。
2. 三条命脉能力是 **实时估值域（五档降级）→ 方向预测域（E1/E3→DDSM→双否决→0.52）→ 组合决策域（只算开口、C/D 不参与、报覆盖占比）**，其余能力为它们服务或为其可信度背书。
3. 全部 9 域共 **41 个能力节点**，其中标「待验证」14 个、「未知」4 个；未知项全部集中在外部数据源口径与 T+3/T+15 基线，已列入 `## 下游交接 → 残留风险`。
4. 能力域与 PRD F-01~F-17 一一映射；任何节点都不引入 PRD 不做清单之外的功能（超额交付禁令）。
5. 不依赖技术选型：本文只描述"用户能感知到什么"，落到哪个模块/接口由 `06/07/08/09` 决定。

### 4. 能力域之间的关键数据流（用户视角）

```
① 持仓总览域 ──取每行估值──▶ ② 实时估值域 ──holdings/valuation──▶ ⑧ 数据接入域（外部源）
      │                              │
      │                              └──置信度──▶ ⑤ 复盘审计域（MAE 统计）
      │
      └──取信号/覆盖──▶ ③ 方向预测域 ──开口集合──▶ ④ 组合决策域
                              │
                              └──开口写盘──▶ ⑤ 复盘审计域 ──账本──▶ ⑦ 引擎观测域
                                                          └──因子摘录──▶ ⑥ 因子治理域

⑨ 系统设置域 ──隐私/数据源健康/注册表──▶ ①⑤⑦
```

**硬规则**：数据流单向——⑧ 是唯一数据入口，①~⑦ 一律从后端 API 取数，前端不得跨域自造（PRD G3）。
