#### F2-21 · 四态全量接线（P0 · UI）
- **输入**：每页真实数据条件（空/加载/错误/成功）。
- **处理**：emptyWhen 全量接线；空态文案按 `03-ui-design-v3.md §4` 逐页定义。
- **输出**：7 页四态可真实触发。
- **异常**：success 前不渲染数字；error 不回退示例数据。
- **验收**：① 7/7 页空态可触发（QA）；② 空态含「为什么空 + 下一步」；③ error 含原因 + 重试；④ empty 下无数字行（断言）。

#### F2-22 · 回填态激活（P0 · UI）
- **输入**：F2-12 回填结果。
- **处理**：时间线圆点、对账徽章、事件链第⑥步联动。
- **输出**：hit/miss 状态全套。
- **异常**：未到期 → 「待回填」；数据缺失 → 「数据缺失待补」。
- **验收**：① hit/miss 与 t1_real 符号一致；② 待回填仅限未到期；③ 事件链第⑥步出值；④ 刷新一致。

#### F2-23 · 长表/可访问性（P1 · UI）
- **输入**：全站长表；键盘交互；dialog。
- **处理**：sticky 表头；`:focus-visible` 焦点环；Esc 关 dialog + 焦点回位；fold hover。
- **输出**：可键盘操作、滚动不丢表头的界面。
- **异常**：旧浏览器不支持 sticky → 降级为普通表头（不报错）。
- **验收**：① sticky 生效；② Tab 可达且焦点可见；③ Esc 可关 dialog；④ 三处基准（sticky/focus/fold-hover）不缺失。
