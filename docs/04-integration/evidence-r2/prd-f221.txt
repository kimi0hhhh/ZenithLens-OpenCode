### 2. 功能详述（输入 / 处理 / 输出 / 异常）

#### F2-01 · 置信度误差通道（P0 · 核心）
- **输入**：valuation_history 逐日估值记录（`mode|code`）；T+1 官方净值（由 F2-16 回补）；accuracy 既有 proxy 口径数据。
- **处理**：当日估值入账 → 净值公布后回算当日误差（估值涨跌 vs 净值涨跌）→ 按 `mode|code` 键逐日累计 MAE 与方向命中率 → 滚动 40 日窗；置信度分档（误差达标/中等/偏大/无）由后端生成，前端只消费。
- **输出**：每只每档 `{conf, mae_rate, dir_hit_rate, n_test, window, reason}`；vsum 市值加权 MAE；徽章置信度配色（F2-20）。
- **异常**：净值未出 → 该日不回算（不填 0）；无法计算 → `conf=unknown` 且**必须带 reason**（缺净值/缺估值/样本不足）；单只样本 <5 → 显示「样本不足」不冒充达标。
- **验收**：① 置信度非 unknown ≥**21/22**（基线 0/22）；② vsum 加权 MAE 由 null → 非 null 且可复算；③ 24h 内产生当日误差记录；④ 下钻含 MAE/n/方向命中率/回测窗四字段。**（待架构裁定：误差回算落盘位置与增量重算代价）**
