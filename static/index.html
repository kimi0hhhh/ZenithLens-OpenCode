LLM 接口 R-UI-33 · 仅用于事件编码，不做最终预测（shadow）

本地存储，不上传、不进日志、不写进任何产物
「测试连接」为本地校验：仅检查配置格式，不发起网络请求（连通性测试未接入）。
三条硬约束（都是踩过的坑）：
① 温度必须为 0，输出必须是纯 JSON 且禁止解释文字。温度 0 也消不掉波动，只能靠结构化短输出压缩。
② 不问"利好还是利空"，改问"是否超出市场预期"。后者常是新闻里的客观表述，可关键词提取、一致性 100%。
③ LLM 编码输出本身必须先过四关回测才能进生产。实测事件维接入 DDSM 三窗口均无增量（价格已 price-in）。
